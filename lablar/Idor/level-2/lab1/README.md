## 🎯 Objective / Amaç

You are a normal NovaMart customer.

Your final objective is:

**Reach the NovaMart Admin Console without knowing the admin password.**

Türkçesi:

**Admin şifresini bilmeden NovaMart Yönetici Paneli'ne ulaş.**

The challenge is based on a chain of **three IDOR/Broken Access Control issues**.


##  Installation / Kurulum

Requirements:

- Python 3.10+
- pip

Install:


pip install -r requirements.txt

python app.py



veya calısmassa



python3 -m pip install -r requirements.txt --break-system-packages

python3 app.py

http://127.0.0.1:5000
