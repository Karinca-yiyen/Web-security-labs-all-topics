## Installation and operation

```bash
cd idor-lab

# 1) Veritabanını oluştur (bir kere çalıştırman yeterli)
# 1) Create the database (you only need to run it once)

php includes/init_db.php

# 2) Sunucuyu başlat (public/ document root olmalı!)
# Start the server (it must be public/document root!).

cd public
php -S 127.0.0.1:1616
```
